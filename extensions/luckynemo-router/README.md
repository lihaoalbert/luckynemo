# LuckyNemo Router

Managed multi-provider model routing and quota reporting for LuckyNemo. The
default endpoint is the LuckyNemo platform proxy placeholder
(`https://kidsai.ibi.ren`, 临时域名, luckynemo.com 备案后切换); operators can override it via the provider
`baseUrl`.

See the [LuckyNemo Router provider docs](../../docs/providers/luckynemo-router.md).
